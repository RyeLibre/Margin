# Margin

A reader for PDF and EPUB books with highlights, notes, a vocabulary list and read-aloud
(a natural neural voice that works offline, or your device's own voices).

- **Windows app**: double-click `Install Margin (app).cmd` (builds `Margin.exe` with the
  .NET Framework that comes with Windows, and adds Desktop and Start-menu shortcuts).
- **Android app**: download `Margin.apk` from the
  [latest release](https://github.com/RyeLibre/margin/releases/latest) on your phone and open it.
  GitHub builds it from the `android/` folder each time the code changes.
- **Browser**: `Start Margin.bat` (Windows) or `python3 serve.py`, then open http://localhost:8765/.

Built with PDF.js (Apache 2.0) and Kokoro-82M through kokoro-js (Apache 2.0).
